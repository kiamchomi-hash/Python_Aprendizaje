Metodo de Trabajo

Regla operativa para documentar herramientas nuevas como una guia manual autosuficiente.

Regla Principal

Cuando haya que instalar una herramienta, la guia debe estar escrita como si se hiciera manualmente, sin depender de ningun asistente.

  1. Primero se explica que es la herramienta y para que sirve.
  2. Despues se explica por que se necesita dentro de la hoja de ruta.
  3. Luego se dan los pasos manuales exactos para instalarla.
  4. Se incluye el comando concreto, si existe una instalacion por terminal.
  5. Se explica como verificar que quedo bien instalada.
  6. Se agrega que hacer si aparece un error comun.
  7. Al final se deja un checklist de confirmacion.

Formato De Cada Instalacion

Cada instalacion se documentara con esta estructura:

  1. Que es: descripcion corta.
  2. Por que lo usamos: relacion con la hoja de ruta.
  3. Instalacion manual: pasos exactos para hacerlo a mano.
  4. Comando recomendado: comando visible, si corresponde.
  5. Verificacion: comando para confirmar que quedo bien.
  6. Errores comunes: problema probable y solucion.
  7. Checklist: puntos que confirman que se puede avanzar.

Ejemplo

Ejemplo de guia manual para instalar Python en Windows con winget:

  1. Abrir PowerShell.
  2. Comprobar si winget esta disponible con winget --version.
  3. Ejecutar el comando de instalacion.
  4. Cerrar la terminal y abrir una nueva.
  5. Verificar Python y pip.
winget install -e --id Python.Python.3.12 --accept-package-agreements --accept-source-agreements

Para verificar:

python --version
pip --version
