Configuracion Inicial

Referencia para preparar una PC o un proyecto nuevo. No hace falta memorizar esto; se consulta cuando se necesita.

Idea General

La configuracion inicial prepara las herramientas. Se hace pocas veces. El trabajo diario es otra cosa.

Configuracion inicial = preparar PC y proyecto
Trabajo diario = escribir codigo, probar, guardar y subir cambios

Herramientas Base

  • Python: lenguaje que ejecuta los programas.
  • pip: instala paquetes de Python.
  • VS Code: editor donde se escribe codigo.
  • Extension Python de VS Code: autocompletado, ejecucion y depuracion.
  • Git: guarda versiones del proyecto en la PC.
  • GitHub: guarda una copia online del proyecto.
  • GitHub CLI: permite crear repositorios y autenticarse con GitHub desde terminal.

Instalar En Una PC Nueva

Python

winget install -e --id Python.Python.3.12 --accept-package-agreements --accept-source-agreements

Verificar:

python --version
pip --version

Git

winget install -e --id Git.Git --accept-package-agreements --accept-source-agreements

Verificar:

git --version

VS Code

winget install -e --id Microsoft.VisualStudioCode --accept-package-agreements --accept-source-agreements

Verificar:

code --version

Extension Python de VS Code

code --install-extension ms-python.python

GitHub CLI

winget install -e --id GitHub.cli --accept-package-agreements --accept-source-agreements

Verificar:

gh --version

Configurar Git En Una PC Nueva

Esto se hace una vez por PC. Define la identidad que aparecera en los commits.

git config --global user.name "kiamchomi-hash"
git config --global user.email "kiamchomi@gmail.com"

Verificar:

git config --global user.name
git config --global user.email

Crear Un Proyecto Nuevo Desde Cero

Esto se hace una vez por proyecto.

mkdir MiProyecto
cd MiProyecto
git init

Despues se crea el repositorio en GitHub y se conecta:

git remote add origin https://github.com/USUARIO/NOMBRE_DEL_REPO.git
git branch -M main
git push -u origin main

Bajar Un Proyecto De GitHub A Otra PC

Esto se hace la primera vez que se quiere tener el proyecto en otra computadora.

git clone https://github.com/kiamchomi-hash/Python_Aprendizaje.git
cd Python_Aprendizaje

Trabajo Diario

Esto es lo que se usa todo el tiempo mientras se aprende y se escribe codigo.

python archivo.py
git status
git add .
git commit -m "Mensaje claro del cambio"
git push

Si se trabaja desde otra PC y hay cambios nuevos en GitHub:

git pull
