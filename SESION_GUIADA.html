Fase 1 - Paso 1: Verificar Entorno Base

Objetivo

Confirmar que las herramientas minimas para empezar la ruta estan disponibles: Python, pip, Git y VS Code.

1. Abrir una terminal nueva

Cerrar cualquier PowerShell abierta y abrir una nueva. Esto permite que Windows recargue las variables de entorno, especialmente despues de instalar Python.

2. Verificar Python

Ejecutar:

python --version

Resultado esperado:

Python 3.12.10

3. Verificar pip

Ejecutar:

pip --version

Resultado esperado aproximado:

pip 25.x from ... Python 3.12

4. Verificar Git

Ejecutar:

git --version

Resultado esperado:

git version 2.53.0.windows.1

5. Verificar VS Code

Ejecutar:

code --version

Resultado esperado: varias lineas. La primera debe mostrar la version de VS Code.

Comandos De Verificacion Juntos

Si se quiere verificar todo de una vez, ejecutar:

python --version
pip --version
git --version
code --version

Configurar Identidad De Git

Git necesita un nombre y un email para asociarlos a cada commit. Configurarlo una vez a nivel global:

git config --global user.name "Tu Nombre"
git config --global user.email "tu-email@example.com"

Ejemplo:

git config --global user.name "Matias Apellido"
git config --global user.email "matias@email.com"

Verificar la configuracion:

git config --global user.name
git config --global user.email

Configuracion elegida

Para esta maquina se usara el usuario de GitHub como nombre visible y el email indicado:

git config --global user.name "kiamchomi-hash"
git config --global user.email "kiamchomi@gmail.com"

Errores Comunes

  • Si python --version abre Microsoft Store o dice que no se encontro Python, revisar los alias de ejecucion de aplicaciones de Windows o reinstalar Python con la opcion de agregar al PATH.
  • Si pip --version falla, probar python -m pip --version.
  • Si code --version falla, abrir VS Code y activar el comando de terminal desde la instalacion o reinstalar marcando la opcion de agregar al PATH.
  • Si Git no muestra nombre o email, ejecutar los comandos de configuracion global.
  • Si aparece >>>, estas dentro del interprete interactivo de Python. Para volver a PowerShell, escribir exit() y presionar Enter.

Corregir Python En PATH

Que es PATH

PATH es la lista de carpetas donde Windows busca programas cuando se escribe un comando como python o pip.

Problema detectado

Python esta instalado, pero la terminal no lo encuentra por nombre. La ruta real es:

C:\Users\matia\AppData\Local\Programs\Python\Python312\python.exe

Correccion manual

  1. Abrir Configuracion de Windows.
  2. Buscar Variables de entorno.
  3. Entrar en Variables de entorno.
  4. Editar la variable de usuario Path.
  5. Agregar estas dos rutas:
C:\Users\matia\AppData\Local\Programs\Python\Python312\
C:\Users\matia\AppData\Local\Programs\Python\Python312\Scripts\

Correccion por terminal

$pythonDir = "$env:LocalAppData\Programs\Python\Python312"
$scriptsDir = "$pythonDir\Scripts"
$currentPath = [Environment]::GetEnvironmentVariable("Path", "User")
[Environment]::SetEnvironmentVariable("Path", "$pythonDir;$scriptsDir;$currentPath", "User")

Verificacion

Cerrar PowerShell, abrir una nueva y ejecutar:

python --version
pip --version

Siguiente Paso: Git Basico

Objetivo

Guardar el avance con control de versiones para empezar a trabajar como en un proyecto real.

Que es Git

Git es un sistema de control de versiones. Sirve para guardar estados del proyecto, revisar cambios, volver a versiones anteriores y trabajar con repositorios remotos como GitHub.

Conceptos minimos

  • git init: convierte una carpeta en repositorio Git.
  • git status: muestra que archivos cambiaron.
  • git add .: prepara todos los cambios de la carpeta actual para guardarlos en un commit.
  • git commit: guarda una version del proyecto con un mensaje.

Pasos manuales

  1. Verificar si la carpeta ya es un repositorio Git.
  2. Si no lo es, inicializar Git.
  3. Revisar el estado de archivos.
  4. Agregar archivos relevantes.
  5. Crear el primer commit.

Comandos

git status
git init
git status
git add .
git commit -m "Agregar entorno inicial de aprendizaje Python"

Resultado esperado

Despues del commit, git status deberia indicar que no hay cambios pendientes o mostrar solo archivos que todavia no se eligieron para guardar.

Instalacion Para Escribir Codigo Rapido

Objetivo

Dejar listo el entorno minimo para empezar a escribir Python en VS Code con autocompletado, linting basico, ejecucion de scripts y gestion de paquetes.

Herramientas necesarias

  • pip: gestor de paquetes incluido con Python.

  • VS Code: editor de codigo.

  2. Ir a Extensions.
  3. Buscar Python.
  4. Instalar la extension oficial de Microsoft: ms-python.python.

Instalacion por terminal

Verificacion

python --version
pip --version
git --version
code --list-extensions

Subir Proyecto A GitHub

Objetivo

Publicar el repositorio local en GitHub para que quede disponible online en la cuenta kiamchomi-hash.

Que es un remoto

Un remoto es la direccion online del repositorio. Normalmente se llama origin y apunta a GitHub.

Pasos manuales en GitHub

  1. Entrar a https://github.com/new.
  2. Crear un repositorio llamado Python_Aprendizaje.
  3. Elegir visibilidad Public.
  4. No agregar README, .gitignore ni licencia desde GitHub, porque el repositorio local ya tiene archivos.
  5. Crear el repositorio.

Comandos locales manuales

git branch -M main
git remote add origin https://github.com/kiamchomi-hash/Python_Aprendizaje.git
git push -u origin main

Comando usado con GitHub CLI

gh repo create Python_Aprendizaje --public --source . --remote origin --push

Normalizar rama principal

En repositorios nuevos es habitual usar main como rama principal.

git branch -M main
git push -u origin main
gh repo edit kiamchomi-hash/Python_Aprendizaje --default-branch main
git push origin --delete master

Verificacion

Despues del push, abrir:

https://github.com/kiamchomi-hash/Python_Aprendizaje

Si falta GitHub CLI

gh es la herramienta oficial de GitHub para crear repositorios, autenticarse y trabajar con GitHub desde la terminal.

Instalacion manual en Windows con winget:

winget install -e --id GitHub.cli

Verificacion:

gh --version
gh auth status

Si no hay sesion iniciada, autenticarse con:

gh auth login
