Entender el flujo completo entre PC, Git y GitHub

GitGitHubRepositorios

Ya se entendio que GitHub funciona como copia online del proyecto y que Git maneja el historial local antes de subirlo.

Mapa mental:

VS Code  ->  Git local  ->  GitHub  ->  Otra PC

Comandos principales del trabajo diario:

git status = ver que archivos cambiaron
git add archivo.py = preparar un archivo para guardarlo
git commit -m "mensaje" = guardar una version en tu PC
git push = subir esa version a GitHub

Comandos para usar el proyecto en otra computadora:

git clone URL = bajar el proyecto por primera vez desde GitHub
git pull = traer cambios nuevos desde GitHub a una PC que ya tenia el proyecto

Flujo completo en tu PC:

python holamundo.py
git status
git add holamundo.py
git commit -m "Practicar print"
git push
